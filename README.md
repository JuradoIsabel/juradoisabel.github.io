# María Isabel Jurado del Prisco — personal website

A lightweight, responsive portfolio site built with plain HTML and CSS for GitHub Pages.

## Run locally

Open `index.html` in a browser. The CV link expects the PDF at `assets/Isabel_Jurado_CV.pdf`.

## Publish with GitHub Pages

This personal-site repository must be named `juradoisabel.github.io` and belong to the `JuradoIsabel` account. In the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save. GitHub Pages will publish the site at <https://juradoisabel.github.io>.

## Commit and push changes

After Git is installed and the project is connected to its GitHub repository:

```powershell
git add .
git commit -m "Update personal website"
git push
```
